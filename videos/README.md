# Transcrições e notas das palestras

Fonte principal: série *O Profeta* — Lúcia Helena Galvão (Nova Acrópole Brasil).

Um arquivo por capítulo. Onde as legendas do YouTube estavam desativadas (`a-beleza`, `a-morte`), gravaram-se notas a partir da descrição oficial do episódio. `chegada-do-navio` e `a-despedida` usam material introdutório/contextual da série.

Os comentários publicados no site **não** reproduzem a fala oral: são ensaios elaborados em prosa filosófica.
